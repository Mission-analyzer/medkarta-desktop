# Медкарта для Windows, версия 0.3.1

## О программе

«Медкарта» — личный архив медицинских документов: анализов, протоколов УЗИ и других исследований, заключений врачей
и выписок. Она помогает держать документы в одном месте, видеть, как меняются показатели со временем, и быстро находить
нужное перед визитом к врачу. В одном архиве можно вести документы нескольких человек.

## Как она работает

- **Документ.** Вы добавляете PDF или фото. Оригинал сохраняется в архиве без изменений.
- **Распознавание.** Программа переносит содержимое бланка в таблицу: исследования, показатели, значения, единицы и нормы.
  Результат открывается на проверку, и сохраняется только то, что вы подтвердили. Данные можно вводить и вручную.
- **Справочник.** Одни и те же показатели в разных лабораториях называются и измеряются по-разному. Встроенный справочник
  сводит их к одному названию и одной единице, чтобы результаты из разных мест можно было сравнивать.
- **Нормы и отметки.** Значение сравнивается с нормой из самого бланка, а если её нет — со справочной нормой по полу
  и возрасту. Отклонения помечаются.
- **Динамика.** Числовые показатели собираются в графики, находки исследований хранятся с размерами.
- **Хранение.** Архив — это папка с базой и оригиналами на вашем компьютере или флешке. Программа никуда её не отправляет;
  исключение — автоматическое распознавание через внешний сервис, если вы его включили.

Программа не ставит диагнозов и не заменяет врача.

Личный архив анализов и исследований: PDF и фото бланков, распознавание показателей,
отметки «выше/ниже нормы», графики показателей во времени. Данные хранятся только у вас на диске.

## Что нужно

- Windows 10 или 11 (компонент WebView2 в них уже есть).
- Python 3.13 с python.org. При установке отметьте «Add python.exe to PATH».
  На Python 3.14 программа может не запуститься: библиотека, через которую pywebview рисует окно (pythonnet),
  поддерживает 3.14 не во всех версиях.

## Запуск

1. Распакуйте папку `medkarta` куда угодно, например в `D:\Medkarta-app`.
2. Дважды щёлкните `run.bat`. Первый запуск дольше: создаётся окружение `.venv` и ставятся библиотеки.

## Сборка в .exe

Дважды щёлкните `build.bat`. Готовая программа появится в `dist\Medkarta\Medkarta.exe`.
Папку `dist\Medkarta` можно перенести куда угодно и сделать ярлык на рабочий стол. Python ей больше не нужен.

## Как устроена работа: исходники — главные

Папка с исходниками (например, `E:\Medkarta-app`) — основная версия программы. Обновления приходят как новые
файлы исходников, их кладут в эту папку с заменой (папку `.venv` не трогать) и проверяют через `run.bat`.
`.exe` собирается реже, когда накопились изменения, через `build.bat`.

Чтобы при запуске из исходников работать с архивом на флешке: «Настройки» → «Выбрать другую папку» →
папка `data` на флешке. Если флешка получит другую букву диска, выберите папку заново.

Историю изменений удобно хранить в git: в папке уже есть `.gitignore`, который не пускает в репозиторий
окружение, сборки и личные данные (базу, файлы, настройки с ключом). Что менялось — в `CHANGELOG.md`.

## Языки

Интерфейс: українська, русский, English. Язык выбирается в «Настройках», при первом запуске берётся язык Windows.
Тексты интерфейса — `ui/i18n.js`, сообщения Python-части — `i18n.py`, названия показателей — колонки
«Название (рус./укр./англ.)» в справочнике. Чтобы добавить язык, скопируйте блок `en` в обоих файлах и переведите.

## Переносная версия на флешке

Чтобы на рабочем компьютере не оставалось ни программы, ни архива:

1. **Дома** запустите `build.bat`. Он соберёт чистую `dist\Medkarta` без личных данных и положит туда `portable.txt`
   (он включает переносной режим).
2. Первый раз скопируйте папку `dist\Medkarta` целиком на флешку и положите архив в её подпапку `data`.
   При следующих обновлениях копируйте на флешку только `Medkarta.exe` и папку `_internal` —
   **никогда не заменяйте `data` и `settings.json`**.
3. На любом компьютере запускайте `Medkarta.exe` прямо с флешки. Python там не нужен.

В переносном режиме настройки, ключ API и архив лежат только на флешке, путь к архиву не зависит от буквы диска,
а окно программы работает без кэша на диске. На рабочем компьютере не запускайте `run.bat`:
он создаёт окружение Python и кэш библиотек на этом компьютере.

После переноса дома можно удалить старые копии: папку `Документы\Medkarta` и `%APPDATA%\Medkarta`.

## Первые шаги

1. **Люди** — добавьте себя: имя, пол, дату рождения. По ним выбираются нормы, когда в бланке их нет.
2. **Настройки** — вставьте ключ Anthropic API (console.anthropic.com), если хотите, чтобы бланки распознавались сами.
   Без ключа программа работает как архив с ручным вводом. Распознавание платное, по тарифам API;
   файл бланка при этом отправляется в Anthropic.
3. **Добавить из файла** — выберите один или несколько PDF или фото. Каждый файл откроется на проверку:
   сверьте строки с бланком, при необходимости выберите показатель в колонке «Показатель в справочнике»
   (выбор запомнится для таких же строк) и нажмите «Сохранить».

## Где данные

По умолчанию `Документы\Medkarta`: база `medkarta.db` и подпапка `files` с оригиналами.
Для резервной копии скопируйте папку целиком. Если положить её в OneDrive или Google Drive,
копия будет обновляться сама. Папку можно сменить в «Настройках».
Настройки и ключ API лежат в `%APPDATA%\Medkarta\settings.json`.

## Справочник

`reference\medkarta-spravochnik.xlsx` — справочник показателей: анализы крови (ОАК, биохимия, электролиты,
железо, витамины, липиды, углеводный обмен, гормоны), мочи и кала, размеры по УЗИ и дуплексу сосудов шеи. После правок в Excel запустите
`update_reference.bat`: он пересоберёт `reference\reference.json`. Затем перезапустите программу
(для .exe — пересоберите через `build.bat`). При первом запуске с новым справочником программа сама
пересопоставит уже внесённые документы.

## Что уже умеет

- Импорт PDF, JPG, PNG, WebP; повторный файл узнаётся по хешу, повторный заказ — по номеру.
- Распознавание любых лабораторий через Claude; сопоставление со справочником по правилам из документа
  «Медкарта — модель данных» (кириллица в аббревиатурах, апострофы, префиксы разделов, % и абсолютные значения).
- Пересчёт единиц, нормы из бланка с проверкой на правдоподобие, запасные нормы из справочника по полу и возрасту.
- Строки, требующие внимания, помечаются «проверить» с причиной.
- УЗИ, МРТ, гистология: заключение, размеры, находки с размерами и категориями (TI-RADS и т.п.).
- Графики показателей: полоса нормы, значения «меньше чем», разрыв при смене методики.
- Несколько человек в одном архиве.
- Три языка интерфейса, переносной режим, встроенная справка.

## Чего пока нет

- В справочнике пока нет фракций липидов, свёртываемости, С-реактивного белка, онкомаркеров (кроме ПСА) и ЭхоКГ.
  Неопознанные показатели всё равно сохраняются и строят графики под своим названием.
- Связь находок между исследованиями (очаги) — после того как появятся реальные протоколы УЗИ.
- Экспорт отчёта для врача.

## Файлы проекта

| Файл | Что делает |
| --- | --- |
| `app.py` | Окно программы и функции, которые вызывает интерфейс |
| `db.py` | База SQLite: схема и запросы |
| `reference.py` | Сопоставление строк бланка со справочником, единицы, нормы, отметки |
| `recognize.py` | Распознавание через Anthropic API |
| `ui/index.html` | Интерфейс |
| `ui/i18n.js` | Тексты интерфейса на всех языках, включая справку |
| `i18n.py` | Сообщения Python-части на всех языках |
| `tools/xlsx_to_json.py` | Сборка справочника из Excel |

Запуск с инструментами разработчика для отладки интерфейса: `python app.py --debug`.

# Справочник лабораторных показателей и норм «Медкарты»

Открытый справочник для разбора медицинских бланков: что как называется в разных лабораториях,
в каких единицах приходит, как пересчитывается и какие у показателя справочные нормы
с учётом пола и возраста. Собран для программы [«Медкарта»](../README.md) и лежит в её репозитории, в папке `reference/`. Ориентирован на бланки украинских лабораторий (Сінево, CSD LAB, Діла), но пригоден для любого проекта.

> **Важно.** Это справочные данные, а не медицинские рекомендации. Нормы различаются между лабораториями,
> методиками и реактивами; главной всегда остаётся норма из бланка вашей лаборатории. Результаты анализов
> интерпретирует врач.

Листы: `analytes` (показатели), `aliases` (написания в бланках), `units` (единицы), `conversions` (пересчёт),
`norms` (нормы), `panels` (составы стандартных анализов).

## Как устроены нормы

- У каждой строки нормы есть **источник**: бланк лаборатории, опубликованный образец бланка или рецензируемая статья
  и международные рекомендации (ESC/EAS, KDIGO, ESH/ESC, Radiopaedia и др.).
- Нормы задаются по **полу** (`m`, `f`, `any`), **возрасту** (от/до, лет) и **особому состоянию** (например, триместр беременности).
- Если подходит несколько норм, предпочтение получает норма той же лаборатории, затем — по полу, затем — с более узким
  возрастным диапазоном. Пример: ПСА у мужчины 62 лет — граница 4,5 нг/мл (возрастные нормы Oesterling, 1993),
  а не общая 2,5.
- Для показателей, где норма сильно зависит от реактива (АЧТВ, фибриноген, ферменты), справочной нормы нет
  намеренно: используется только норма из бланка.

## Чего пока нет

ЭхоКГ и ЭКГ, онкомаркеры кроме ПСА, кардиомаркеры (тропонин, NT-proBNP), часть гормонов с нормами по фазам цикла,
инфекционная серология, группа крови. Многие нормы взяты из одного источника; для части показателей есть нормы
только одного пола или только для взрослых.
